# AI-Wealth-Management-Projects
Portfolio of AI projects for wealth management. Code samples for recruiters, not a client product.

This repository is a portfolio, not a product. It shows code I have written to apply AI to wealth-management work, such as answering questions on a fact sheet or prospectus with citations. It is meant for recruiters and firms evaluating an advisor with AI skills. It is not a client tool and it does not provide investment advice.
