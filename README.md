# AI-Wealth-Management-Projects

Portfolio of AI projects for wealth management. Code samples for recruiters, not a client product.

This repository is a portfolio, not a product. It is meant for recruiters and firms evaluating an advisor with AI skills. It is not a client tool and it does not provide investment advice.

## Projects

- [`wealth-ips-prototype`](wealth-ips-prototype/) — Fictional robo-advisor: questionnaire, automatic mix, paper account, auto-rebalance. Paper money only.
